# ग्राम पंचायत सांजू — वेबसाइट

ग्राम पंचायत सांजू (तहसील सांजू, ज़िला नागौर, राजस्थान) की आधिकारिक वेबसाइट।
यह मोबाइल-फ्रेंडली, हिंदी, मल्टी-पेज स्टैटिक वेबसाइट है, जो GitHub Pages पर मुफ़्त चलती है।

**लाइव:** https://shritirupati.github.io/Gram-panchayat/

## जानकारी कैसे बदलें

**सारी जानकारी एक ही फ़ाइल `js/data.js` में है।** नाम, नंबर, योजनाएँ, शिकायतें,
विकास कार्य, बजट और सूचनाएँ यहीं बदलें। HTML फ़ाइलों को छूने की ज़रूरत नहीं है।

- **फ़ोटो:** फ़ोटो को `images/` में डालें और `data.js` में उसका रास्ता लिखें, जैसे `photo: "images/sarpanch.jpg"`।
- **पहले-बाद की फ़ोटो:** विकास कार्य में `pehle` और `baad` भरें।
- **नमूना पट्टी:** असली जानकारी भरने के बाद `demoMode: false` कर दें।
- `images/demo/` में रखे चित्र सिर्फ़ नमूने हैं। असली फ़ोटो आने पर इन्हें बदल दें।

## शिकायत व्यवस्था कैसे काम करती है

1. नागरिक फ़ॉर्म भरता है। उसे एक **शिकायत संख्या** (जैसे `SJ-2611-1234`) मिलती है और संदेश पंचायत के WhatsApp पर चला जाता है।
2. पंचायत उस शिकायत को `data.js` की `shikayatein` सूची में जोड़ती है और स्थिति (`दर्ज` → `प्रगति पर` → `समाधान`) व समाधान तिथि अपडेट करती है।
3. नागरिक अपनी शिकायत संख्या डालकर स्थिति देख सकता है। सार्वजनिक रजिस्टर में सबको दिखता है कि शिकायत कब दर्ज हुई, कब हल हुई और कितने दिन लगे। रजिस्टर में शिकायतकर्ता का नाम और मोबाइल नंबर नहीं दिखता।

**आसान तरीका (Google Sheet):** शिकायतें फ़ोन से Google Sheet में भी अपडेट की जा सकती हैं। इसके लिए:
- Sheet में ये कॉलम बनाएँ: `id, darj, ward, vibhag, vishay, sthiti, hal, tippani`
- *File → Share → Publish to web → CSV* चुनें।
- मिला हुआ लिंक `data.js` में `shikayatSheetCsv` में डाल दें।

## ऑनलाइन करना (GitHub Pages)
*Settings → Pages → Deploy from a branch → `main` / `(root)`* चुनें। `main` पर हर push के बाद वेबसाइट अपने आप अपडेट हो जाती है।
