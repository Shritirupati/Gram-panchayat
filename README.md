# ग्राम पंचायत वेबसाइट

गाँव की ग्राम पंचायत / सरपंच के लिए एक सरल, मोबाइल-फ्रेंडली हिंदी वेबसाइट।

## इसमें क्या-क्या है
- गाँव का परिचय और आँकड़े
- सरपंच का संदेश
- पंचायत के सदस्य
- सरकारी योजनाएँ (आधिकारिक लिंक के साथ)
- विकास कार्य (पूर्ण / प्रगति पर / प्रस्तावित फ़िल्टर)
- सूचना पट और चलती हुई ताज़ा सूचना
- ज़रूरी हेल्पलाइन नंबर
- फ़ोटो गैलरी
- शिकायत / सुझाव फ़ॉर्म, जो सीधे पंचायत के WhatsApp पर जाता है
- संपर्क जानकारी और Google Map

## जानकारी कैसे बदलें
सारी जानकारी **`js/data.js`** फ़ाइल में है। `[चौकोर कोष्ठक]` वाली चीज़ें असली जानकारी से बदल दें।
फ़ोटो `images/` फ़ोल्डर में डालें और `data.js` में उसका नाम लिखें, जैसे `photo: "images/sarpanch.jpg"`।

## वेबसाइट ऑनलाइन कैसे करें (मुफ़्त)
1. GitHub पर repo खोलें → **Settings → Pages**
2. *Source* में **Deploy from a branch** चुनें, branch **main** और फ़ोल्डर **/ (root)** चुनें, फिर Save दबाएँ
3. 1–2 मिनट बाद वेबसाइट `https://<username>.github.io/Gram-panchayat/` पर खुल जाएगी

## कंप्यूटर पर देखने के लिए
`index.html` को ब्राउज़र में खोल दें। इसे चलाने के लिए कुछ भी इंस्टॉल नहीं करना पड़ता।
